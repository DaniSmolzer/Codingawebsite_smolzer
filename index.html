About

Hi there! My name is Dani, and I am a graphic designer. I have been studying graphic design for 5 years now. I've taken many classes and have a lot of experience using many Adobe products. I enjoy using fun colors, and like my designs to have an overall theme or vibe to them. I've always had a love for art, ever since I was little, and learning about art is one of my favorite things to do. I hope you enjoy looking through my portfolio, and if you're interested I'd love to connect and work on a project with you.

About this project

This website was created by Dani Smolzer as a student project for ARTD 245: Web Design at North Central College in Naperville, IL, in 2026. All original graphics were created using Photoshop, Illustrator, or Procreate, and the site was hand-coded using HTML and CSS in Dreamweaver. Text content and design theory are adapted from Flux Academy, Tilda Education, and Dribbble articles.
